# Smart Party Plus v1.0.9

## First-page visual corrections

- **Smart Party** now uses the exact approved compact-sample gradient on every theme: soft white → pink → violet → cyan.
- The separate `+` badge now also uses the sample's cyan → violet → pink gradient, dark symbol and cyan edge instead of inheriting the selected theme.
- The compact micro-brand color and soft title glow now match the approved sample.

## Correct new-user default

- A brand-new installation now starts on **Lobby Neon** with its linked **Violet + Midnight** bubbles.
- Existing users keep whichever theme and bubble they already selected; this is only the missing-preference default.
- Night Purple remains available in the picker but is no longer labelled as the default.

## Dark digital matrix cells

- Night Purple's digital feature cells now use the approved dark translucent `#131231 → #050c1d` treatment.
- The prior alpha override that could turn Night Purple's translucent white token into an almost solid-white cell has been removed.
- Matrix text uses the sample's soft `#e8e5fa` instead of stark white, while all seven features and the compact `4 + 3` footprint remain unchanged.

## Preserved identity and behavior

- App/package/launcher identity remains **Smart Party Plus** (`app.party.wpnative`).
- Permanent update certificate and exact ACT7/Synkplay Android v0.23.0 MPV engine remain unchanged.
- All accepted Room, sync, media, chat, call, DP, typing, rename and notification behavior remains preserved.

## Release identity

- Version: **1.0.9** (`versionCode 13`)
