# Smart Party Plus v1.0.2

A focused Party Room header spacing update, signed with the same permanent Smart Party Plus release key.

## Changed

- The Party Room header now uses the compact label **Smart Party +**.
- This keeps the branding from entering or crowding the live **online** status pill on narrow phones.
- The application name, launcher label and all branding outside the Room remain **Smart Party Plus**.

## Preserved

- The v1.0.1 first-page typing/background fix and all previously accepted behavior remain unchanged.
- Exact ACT7/Synkplay Android v0.23.0 native MPV/FFmpeg engine remains pinned and verified.
- Package ID remains `app.party.wpnative`.
